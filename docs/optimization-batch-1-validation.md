## 已验证的行为

- 任务与积分预留同事务创建；重复任务 ID、全站/用户容量拒绝均不留下额外冻结或预留。
- 中断任务失败状态与退款同事务提交，写入失败时一起回滚；重试只结算一次。
- 已成功结算的任务不会因服务重启或最终响应写入失败再次退款或扣费。
- 老版本无任务关联的未结算预留保持不变，留给管理员核对。
- 完成响应可跨启动查询，非登录用户 401、其他登录用户 404；终态过期清理不删除 pending。
- 真实子进程接收异步生图后，在上游等待期间 SIGKILL；重新启动返回安全中断错误、释放冻结积分，不重放上游请求。
- 关闭服务时拒绝新预留与 HTTP 异步提交，已接收任务完成/失败后再关闭数据库。
- 现有生图成功、部分成功、上游失败、安全文案、图片历史、积分幂等与权限相关测试通过。

测试先行证据：任务 Store 未实现时六项恢复测试失败；接入前两项重启 API 测试返回 404；关闭服务拒绝新预留测试先报 Missing expected exception，增加关闭状态后通过。
