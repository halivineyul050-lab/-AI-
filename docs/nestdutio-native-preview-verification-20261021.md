# 原生工程浏览器模拟预览验证

## 实现

右侧默认“手机预览”，可随时切换“源码”。采用现有独立项目域名、过期预览令牌及 CSP，不在主站执行生成脚本。原生工程通过临时 web 包装运行，未修改原生文件、ZIP 导出、采购成本、积分或微信验证状态。无 AppID 可使用模拟预览，不需要重新生成已有工程或额外调用模型。

支持常见 WXML 布局、文本、条件和循环、输入与点击、表单字段、Page.setData、生命周期、本地存储、页面导航与提示。保持无 ID 输入框焦点、标签选择器和 WXML 自闭合结构。未知能力显示提示，微信通知、登录、支付和权限等仍需微信环境验证；自定义组件、模板和部分复杂组件不保证完整还原。独立预览不可用、表达式无法解析或包装超过大小限制时回退源码并说明原因。

## 验证

- NeStudio 全部相关测试：145 项通过、0 失败。日志为本机临时目录 `native-preview-all-nestdutio.log`。
- 最终表单修复后复跑原生交互、UI 和 API：6 项全部通过，日志 `native-preview-final.log`。
- 浏览器验证：点击计数、带 ID 与无 ID 逐键输入、混合表达式、条件、自闭合节点、循环、标签样式、命名表单提交、本地存储刷新、下一页与返回、不支持的微信能力提示。
- 工作台验证：默认隔离 iframe、预览/源码切换且不重载交互状态、390px 无横向溢出、预览失败仍可查看源码、原生 ZIP 不变及其他用户无法预览。
- 安全与回归：preview CSP 禁止外部网络及 unsafe-eval；既有网页预览、令牌、存储隔离、运行错误和导出测试通过。新入口与运行时语法检查通过。
- 复用了之前实际生成的房贷原生工程，独立计算每月还款和总利息后核验计算/重置。模型原验收中的利息数值为 109273.31，独立公式与实际程序得到 109273.94；测试使用独立公式，不采信该模型预期。
- 该旧工程还有 `totalPayment` 与 `totalPay`、`error` 与 `errorMsg` 字段不一致问题，属于生成源码本身的问题。本次未修改原始工程以掩盖错误；模拟器中缺失字段为空，不回落到浏览器同名 DOM 全局变量。
- 独立代码审查发现的无 ID 输入焦点、CSS 标签选择器、自闭合节点及表单字段聚合问题均已补回归并修复。
