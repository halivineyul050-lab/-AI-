# 模型配置库使用说明

以超级管理员账号登录泥壳后台，在图片平台、小助手、交互讲解或NeStudio的独立接入表单中找到“配置库”。

1. 填写接口、模型（聊天模块）及KEY，输入一个方案名称，点击“保存当前为方案”。若当前模块已经保存KEY且地址一致，可留空KEY直接另存；也可选用已有方案后用新名称另存。
2. 在“已保存方案”中选择方案，点击“选用方案”。这一步只填充表单，点击模块原有保存按钮才真正生效。
3. 其他对话模块可点击“刷新方案”后选用同一聊天方案。图片平台方案与聊天方案分开，图片具体模型仍在平台原有模型管理中设置。
4. 更换地址、输入新KEY、清除KEY、切换继承或重新加载会清除临时方案引用；不会自动把旧KEY发到新接口。
5. 删除需要连续确认两次；只删除库中方案，不会删除已经保存到模块的活动配置。相同名称不会覆盖，需另取名称或先删除旧方案。

KEY在服务器数据库中使用现有加密机制保存，不会回传明文、回填输入框、写入浏览器本地存储，也不提供明文导出。保存后输入框留空代表不会重新显示KEY。当前最多100套方案，配置库管理与引用均需要超级管理员权限。

建议先使用新名称另存验证；修改或切换活动配置前核对接口、模型及本模块的启用、积分和限额设置。
