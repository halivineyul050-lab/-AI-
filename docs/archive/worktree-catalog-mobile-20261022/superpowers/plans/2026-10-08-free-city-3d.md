# 自由都市 3D 改造 Implementation Plan

> **For agentic workers:** Execute this plan task by task in the current isolated worktree. Each task ends with a focused verification checkpoint.

**Goal:** 将附件中的自由都市原型改造成写实街机风格的独立 Three.js 城市游戏，并接入泥壳 AI 工具站的路由、游戏大厅和 sitemap。

**Architecture:** 新游戏放入 `public/games/free-city-3d/`。`index.html` 提供菜单/HUD 和延迟启动，`main.js` 负责渲染循环、输入和 UI，`simulation.mjs` 保存可单测的驾驶/交通状态更新，`world.js` 负责 Three.js 城市、车辆和角色场景。Three.js 从站内现有 `/games/yiren-buche/three.min.js` 延迟加载；不改现有游戏文件，不使用外部资产。

**Tech Stack:** Node.js 22、浏览器原生 ES modules、站内 Three.js r160、现有 Node test runner、现有静态游戏路由。

## Global Constraints

- 目标为写实街机城市，不做照片级模拟。
- 所有游戏资源同源；不访问外部 CDN，不新增 npm 依赖或复制 Three.js。
- 游戏开始前只加载菜单；点击开始后才请求 Three.js 并创建世界。
- 保留步行、上下车、送货、奖励、通缉、警车、暂停、小地图、键盘与触屏玩法。
- 使用独立游戏路由白名单和已有路径穿越保护。
- 高画质可用有限范围阴影；低画质降低 DPR、关闭阴影并减少远处动态实体。
- 按 `docs/production-release.md` 测试、制作完整发布包、发布和公网核验；禁止直接编辑线上目录。

## File Structure

- `public/games/free-city-3d/index.html` — 菜单、Canvas、HUD、触控区、无 WebGL 和加载状态。
- `public/games/free-city-3d/style.css` — 全屏布局、HUD、菜单和手机布局。
- `public/games/free-city-3d/main.js` — 延迟引擎加载、场景协调、渲染循环、键鼠/触控输入、任务/HUD 状态。
- `public/games/free-city-3d/simulation.mjs` — 无 DOM/Three.js 依赖的车辆、碰撞、交通实体运动函数。
- `public/games/free-city-3d/world.js` — 城市程序化几何、建筑立面、道路道具、车/人模型、光照、阴影和距离裁剪。
- `tests/free-city-3d-simulation.test.mjs` — 车辆步进、转向、制动、碰撞和 delta 上限测试。
- `tests/production-games.test.mjs` — 新游戏资源路由、路径穿越、返回入口、游戏大厅和 sitemap 覆盖。
- `public/games.html` — 新入口卡片、游戏总数与卡片顺序。
- `server.mjs` — 增加 `free-city-3d` 固定路由分支和 sitemap 项。

**Interfaces:**

- [ ] 使用有固定随机种子的街区生成器构建地面、路面、人行道、路缘、车道线与斑马线；街区内组合差异化高度/屋顶的建筑体、窗格与少量路灯、树木和屋顶设备。
