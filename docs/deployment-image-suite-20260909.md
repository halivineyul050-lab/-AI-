## 公网边界

部署后复查：公网 HTTP ontimo.cn 返回403、页面标题 Non-compliance ICP Filing，转向阿里云备案拦截页；公网 HTTPS 连接被重置。源站服务与功能正常，但尚不能宣称公网访问恢复；需要域名备案/接入状态恢复。此问题部署前已经存在。

基础编辑完全在用户浏览器执行。抠图和增强通过本站服务器执行；图片仅保存任务临时文件。严重失焦、透明物体和毛发边缘不保证修复理想。增强当前针对小图，输入最长512，输出最长1536；大图会先缩小并明确提示。分享链接提取仍仅限本机，未在此次改动中开放公网。
