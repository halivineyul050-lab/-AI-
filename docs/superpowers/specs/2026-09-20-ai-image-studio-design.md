# AI 生图创作台设计规格

## 目标

将现有 `/image-generation` 的“即将上线”占位页升级为一套可操作的前端创作台。页面沿用泥壳AI现有紫色主题与全站导航，布局参考用户提供的居中式生成界面，并为以后接入 GPT 图片生成 API 保留清晰的数据边界。

本次不发送真实生成请求，也不要求登录、额度或云端存储。生成操作使用本地模拟流程和演示结果，让用户可以完整体验从填写提示词到下载或进入画布的路径。

## 页面结构

### 顶部区域

- 保留现有网站导航、品牌 Logo、明暗主题切换和“AI 生图”激活状态。
- 创作区顶部显示“你好，今天想要创作什么？”及一句简短说明。
- 提供“生成”和“画布”两个分段标签。切换时保留当前提示词、参考图和画布内容。

### 生成模式

生成模式使用居中的大卡片，包含：

- 参考图上传入口，支持常见图片格式，上传后显示缩略图，可移除或替换。
- 提示词输入框，最多 1000 字，实时显示字数。
- 画面比例选择：1:1、4:3、3:4、16:9、9:16。
- 风格选择：自动、电影感、插画、3D、写实、国风。
- 生成数量选择：1、2、4 张。
- 紫色渐变“生成图片”按钮。
- 快捷灵感标签。点击标签会把对应描述填入提示词，用户仍可继续编辑。

点击生成后，界面依次呈现准备、生成中和完成状态。进度为本地定时模拟，不进行网络请求。完成后显示与用户选择数量、比例相符的演示结果卡片，并明确标记“演示结果”。每张结果提供下载和“送入画布”操作；页面还提供再次生成入口。

演示结果由站内本地资源组成，不依赖第三方图片地址。下载得到对应的本地演示图片文件。

### 画布模式

画布提供一个有限但完整的图片编辑工作区：

- 可从本地上传图片，也可接收生成模式中的演示结果。
- 图片进入画布后可用指针拖动。
- 选中图片后可通过滑块或控制按钮缩放。
- 可删除当前选中的图片。
- 画布支持常用比例切换，并在切换时保持图片对象和相对位置。
- “导出画布”把当前画布渲染为 PNG 并下载。
- 空画布显示明确的上传和返回生成模式入口。

画布本次只处理位图，不提供文字图层、滤镜、裁剪、多图层排序、撤销历史或云端保存。

## 视觉设计

- 使用项目设计系统中的品牌紫色、表面色、边框色、阴影和文字变量，兼容现有明暗主题。
- 页面背景使用低对比度紫色光晕，核心输入卡使用宽松留白、大圆角和柔和阴影。
- 桌面端创作台最大宽度约 960px，生成结果可在下方展开；不采用右偏双栏布局。
- 移动端把参数行折叠为可换行的紧凑控件，主按钮保持易点击，结果改为单列。
- 所有按钮、标签和表单控件提供清晰的 hover、focus-visible、disabled 和选中状态。
- 动效只用于模式切换、模拟进度和结果出现；系统设置减少动效时取消非必要动画。

## 前端结构

- `image-generation.html` 负责语义结构和无 JavaScript 时仍可理解的基础内容。
- `image-generation.css` 负责创作台、结果网格、画布、响应式和主题样式。
- 新增 `image-generation.js`，集中管理生成表单状态、模拟生成、上传预览、结果操作和画布交互。
- `server.mjs` 把新脚本加入允许提供的静态文件列表。

JavaScript 内部按职责拆分为状态、生成器和画布控制三个小模块。页面状态只保存在当前浏览器内存中；刷新页面会恢复初始状态。

## 数据流

1. 用户输入提示词、选择参数并可上传参考图。
2. 表单校验通过后生成按钮进入忙碌状态，创建本地模拟任务。
3. 模拟任务完成后，依据数量和比例构造演示结果列表。
4. 用户可以直接下载演示图，或把某张图传给画布控制器。
5. 画布控制器加载图片、维护位置与缩放状态，并在导出时绘制到离屏画布生成 PNG。

未来接入 GPT API 时，模拟任务可替换为真实请求适配器，表单、结果区和画布接口保持不变。

## 校验与异常处理

- 空提示词不能开始生成，并在输入区域显示可访问的错误提示。
- 参考图只接受 `image/*`，单文件上限设为 15MB；格式或大小不符合时给出就地提示。
- 生成过程中防止重复提交，切换模式不会启动第二个任务。
- 图片解码失败时显示错误提示，不把损坏对象加入画布。
- 空画布不能导出，导出按钮保持禁用。
- 下载或导出失败时在页面内显示简洁反馈，不使用阻塞式弹窗。

## 可访问性

- 模式切换使用可识别的标签和选中状态。
- 上传控件、参数选择、生成按钮和画布操作都可用键盘访问。
- 生成进度和错误信息通过状态区域向辅助技术播报。
- 装饰图形不进入辅助技术阅读顺序，结果图包含描述性替代文本。

## 测试与验收

自动化测试覆盖：

- 路由正常返回页面，并正确加载 CSS 与 JavaScript。
- 全站导航仍只出现一个 AI 生图入口。
- 页面包含生成/画布模式、提示词、参考图、参数控件和结果状态容器。
- 脚本中没有 GPT API 请求、密钥或外部生成端点。
- 静态脚本通过语法检查。
- 现有项目测试全部通过。

浏览器验收覆盖：

- 桌面端和手机端没有横向溢出或内容偏右。
- 明暗主题均保持可读。
- 快捷标签、参数选择、参考图上传、模拟生成、下载和再次生成可用。
- 演示结果能送入画布；画布可拖动、缩放、删除并导出 PNG。
- 键盘焦点清晰，减少动效设置生效。
