# AI 兴趣小报：轻松社区感前端改版

日期：2026-10-08  
状态：待用户审阅  
范围：用户端全站视觉与响应式体验

## 设计命题

让对 AI 好奇、想找工具或了解新鲜事的人，像逛一份轻松的兴趣小报一样发现内容，并自然进入工具、资讯、教程、创作与小游戏。社区感来自编辑精选、兴趣分类、收藏、投稿和分享入口；当前产品没有评论或动态发布能力，页面不展示虚构的用户讨论、在线人数或社区帖子。

## 视觉方向

- **主体气质：** AI 兴趣小报。页面像一本持续更新、可随手翻阅的数字刊物，轻松、鲜活、有一点俏皮，但不做幼稚卡通，也不采用密集新闻报纸排版。
- **颜色：** 延续现有品牌紫 `#6558F5`、纸面淡紫 `#F6F5FB`、白色内容面、墨色 `#1D1A2B`；增加少量柠檬青 `#DDF36A` 作为“新发现/本期推荐”的栏目贴签。深色主题继续由现有设计 token 驱动，青色贴签需在两种主题下维持对比度。
- **字体与形状：** 沿用系统中文无衬线字体；标题使用更有节奏的字号和短句，正文仍保持易读。栏目标题可配小型索引贴签、纸张折角或手绘感线条，但只选择一种主要装饰语言，不叠加多种拟物效果。
- **标志性细节：** 首页设置一张“小报头版”精选区，以真实的多站点 AI 热点和已收录工具作为编辑内容；用当期栏目贴签串起资讯与工具卡片。贴签仅表达真实内容类别或更新状态，不暗示不存在的编辑/用户行为。

## 页面与信息结构

### 首页

把首页从单一工具搜索入口改成轻量内容首页。顶部用一句短问候和明确的搜索框欢迎用户；紧接着优先展示来自现有 `/api/v1/news/hot` 的少量多站点热点，再展示热门工具、最新收录和已有内容入口。目录数量与人工核验信息降为次级辅助信息，不再占据一个大型统计面板。保留所有现有搜索、热词点击、查看全部、收藏、工具详情和比较行为；热点点击复用已有文章详情抽屉。

### 导航与内容页

收整桌面导航的层级和间距，明确“逛工具、看资讯、学教程、去创作、玩一局”等主要动线；保留分类、价格、收藏、对比、账号、政策及反馈等现有入口。资讯与榜单采用更清楚的编辑栏目层级，但各自继续展示真实热点、文章和排序结果。发现、教程、分类、收藏、对比及说明页延用同一套栏目标题、索引贴签和卡片语汇，不强行改成新闻列表。

### 工具、游戏与账号

- 工具页继续以用户作品/文件和处理预览为视觉中心；以明确的步骤标题、轻松的提示文案和轻量状态贴签统一工作台体验，不更改文件处理流程。
- 游戏目录强化游乐场入口感和游戏类型辨识；玩法画布、HUD、分数、控制方式及各游戏独立配色保持服务于玩法。
- 登录/注册保持可信和简洁；个人中心把收藏、创作历史和账户内容组织为个人兴趣柜，保持敏感账户操作显眼且谨慎。
- 管理后台保留独立运营工作台，不纳入小报式内容布局。

## 布局与响应式

- 桌面采用有主次的两栏或卡片网格，控制首页开场区高度，让热点或工具首屏真实可见；导航优先展示高频入口，次级入口仍有清楚路径。
- 平板逐步收拢网格列数和导航间距，筛选与工具操作可换行。
- 390px 手机优先保证品牌、搜索、导航入口和内容卡片完整可见；Hero、统计及筛选均允许收缩/换行。页面不得产生视口级横向溢出，长文案和长工具名需要安全换行。
- 所有页面保留浅色/深色主题、可见键盘焦点、语义结构、键盘导航、触控可用性及 reduced-motion 支持。

## 数据、交互与边界

- 使用当前工具、文章、热点、教程、游戏和账号数据；若热点 API 暂无结果，显示说明性空状态并继续展示已有工具内容。
- 不新增评论、动态、关注、聊天、在线人数或虚构的社区内容；不新增 API、数据库表、第三方依赖、前端框架或公开路由。
- 保留所有现有公开 URL、业务数据属性、元素 ID、字段名、ARIA 状态、登录/登出和工具处理行为。调整 HTML 时同步核对脚本选择器。
- 主要调整主站 HTML/CSS/必要的少量首页数据装配，工具/游戏/账号页面的样式与外壳。管理数据与权限代码、独立大型游戏 vendor 资产不属于视觉改版。
- 工作区已有大量未提交改动。只修改本设计所涉及的页面文件；不回退、格式化或提交其它现存改动，不制作生产发布包或发布线上。

## 验收标准

1. 首页开场区清楚表达轻松的 AI 兴趣内容定位；真实热点与工具在桌面和手机首屏有明确阅读顺序。
2. 热点 API 的成功、空结果和失败情况都有合适呈现；热点打开已有文章详情，不制造假内容。
3. 导航能容纳当前公开入口，窄屏不裁切，主要动线易发现；所有原链接、路由和操作继续工作。
4. 资讯、榜单、发现、教程、工具、游戏和账号页共享统一的版式语汇，同时保留各页面任务差异。
5. 桌面、平板与 390px 手机宽度不出现页面级横向溢出；深浅主题、焦点样式和 reduced-motion 可用。
6. 任何结构调整均保留既有业务选择器及无障碍状态；不触及 API、数据库、身份权限、游戏算法或生产发布流程。

## 设计自检

- 页面对象具体为希望轻松发现 AI 工具和内容的中文用户，首页任务为发现、阅读或继续探索。
- 社区氛围由实际存在的热点、投稿、收藏与兴趣内容构成，不虚构社交功能。
- 视觉保留既有紫色品牌与无衬线系统，用有限的青柠贴签作为单一记忆点，避开通用米色衬线与深色荧光默认方案。
- 首页复用当前热点 API 与文章抽屉；无结果时不阻断工具目录。
- 已明确用户端页面范围、管理后台例外、响应式、主题、无障碍、数据边界和交互兼容要求，无待定占位符。
