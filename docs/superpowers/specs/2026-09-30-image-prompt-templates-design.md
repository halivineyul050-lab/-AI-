# 生图快捷提示词模板设计

## 目标

让生图页的五个灵感按钮为用户填入完整、可直接生成且可继续编辑的中文提示词，供用户快速开始创作。

## 方案

- 保留“电影感海报、公众号封面、3D 萌宠、国风插画、电商产品图”五个按钮及现有布局。
- 每个按钮继续通过 `data-prompt` 提供内容，由现有点击处理器写入提示词文本框、刷新字数并聚焦输入框。
- 每段提示词使用自然语言交代主体、环境、构图、光线、风格和适用限制；为跨模型使用，不包含供应商专属参数。
- 采用无需填写占位符的具体示例，用户可以在生成前直接改写主题或细节。
- 每条提示词不超过输入框的 1000 字上限。封面模板预留标题区并默认不生成文字；商品模板不要求模型编造品牌或包装文案。

## 验收

1. 页面恰好显示原有五个分类按钮，顺序与名称不变。
2. 每个按钮均含一条超过简短关键词长度、低于 1000 字的完整中文提示词。
3. 提示词包含对应类型的可执行画面信息，且没有未填写的占位符。
4. 点击行为继续由现有代码处理，不修改生成接口或提示词输入流程。
5. 相关测试通过，并按 `docs/production-release.md` 验证完整生产包后发布、核验公网页面并记录发布证据。

## 资料依据

- [OpenAI 图像生成指南](https://openai.com/academy/image-generation/) 建议写清用途、主体、动作、场景、风格，以及需要控制的构图、光线和约束。
- [OpenAI 图像提示指南](https://developers.openai.com/api/docs/guides/image-prompting) 建议复杂请求按场景、主体、细节和约束组织。
- [Adobe Firefly 有效提示词指南](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/writing-effective-text-prompts.html) 建议明确主体与描述词，并补充情绪、风格和光线。
- [公众号封面提示词案例](https://mtgf.cc/learn/article/wechat-cover-prompt) 强调主题明确、主视觉简洁、预留标题留白，并先生成无字底图。
