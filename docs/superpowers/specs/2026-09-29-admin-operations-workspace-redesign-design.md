# 运营后台工作台精修

日期：2026-09-29  
状态：完成后台视觉收尾与本地复核  
所属项目：泥壳 AI 工具站前端逐页重设计

## 目标

收整运营后台的顶栏与移动指标区，让管理者更快定位时间筛选和主要数据，同时保留后台独立工作台结构。

## 视觉方向

- 宽屏下标题、公告/实时状态、时间筛选和刷新操作保持在一条明确的顶栏层级，不让标题折成窄列或操作孤立到下一行。
- 中等桌面宽度将标题与筛选操作分为两行，保持标题完整并让控件自然换行。
- 手机保留可横向浏览并带标签的侧栏导航；实时状态和日期范围尽可能紧凑；核心指标采用双列紧凑卡片，极窄屏回退单列。
- 图表、复杂表格与后台编辑工作区继续使用各自已有的横向滚动和独立面板。

## 功能边界

- 只调整 `public/admin.css`，不修改后台 HTML、JavaScript、请求/API、权限、令牌或数据内容。
- 保留独立后台侧栏、所有现有选择器、按钮、DOM ID、隐藏状态与交互。
- 本地预览只用于观察静态结构；不伪造后台数据，不发布生产，不运行自动化测试。

## 验收标准

- 1440px 宽度下后台标题保持单行，顶栏操作不落入孤立的第二行。
- 1024px 宽度下标题和筛选区层级明确，控件不相互挤压。
- 390px 手机视口下侧栏标签可通过横向滚动访问，核心指标双列排列且卡片没有页面级横向溢出；极窄视口回退单列。
- 390px 手机视口下日期范围控件不会因为按钮换行而额外占用整行高度。
- 图表与表格仍在各自面板内滚动，后台 DOM 与业务脚本保持原样。
