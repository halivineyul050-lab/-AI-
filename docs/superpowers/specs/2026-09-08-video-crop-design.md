# 视频画面裁剪

用户已批准新增站内工具：拖动/缩放裁剪框，原比例/自由/1:1/16:9/9:16/4:3/3:4 预设，精确宽高，实时裁剪预览，保留音频、本地导出、进度和取消。

入口：新增 `/utilities` 工具索引，列出现有 GIF 和新 `/utilities/video-crop` 页面。两工具页面互相可发现，复用品牌和现有工具页 CSS。

裁剪框采用源视频显示尺寸的像素坐标；四角缩放，内部拖动，支持触摸和键盘方向键。预设比例锁定，精确宽高编辑联动另一边；位置和尺寸始终夹在源画面内。导出使用偶数像素以兼容 H.264/yuv420p，界面显示实际输出尺寸。非方形像素视频先标准化为显示尺寸再裁剪；视频旋转由 FFmpeg 自动处理。

浏览器模块 Worker 加载自托管固定版 @ffmpeg/core 0.12.10 单线程 WASM，导出 H.264/AAC MP4，保留首条音轨（如有），不保留隐私元数据。无需上传视频。初次导出需要下载约 31MB 编码资源；只在用户开始导出时加载。输入最大 100MiB、最长 120 秒、显示尺寸不超过 1920x1920，提示长片段和高分辨率受设备性能限制。取消时终止 Worker，释放全部编码内存；新任务使用新 Worker。

编码安全策略仅新增页面和 Worker 支持 wasm-unsafe-eval；保留其他页面 CSP。WASM MIME 为 application/wasm，精确白名单静态托管。许可证与可取得的上游对应源代码位置一起记录。

验证：几何边界/比例/命令参数测试，API 路由/CSP/WASM MIME，完整既有测试；浏览器拖动、比例、宽高、取消后重试、损坏文件和窄屏；独立 ffprobe 校验导出尺寸、时长和音轨。
