# 游戏目录与游戏外壳重设计

日期：2026-09-29  
状态：按已确认的全用户端重设计范围实施  
所属项目：泥壳 AI 工具站前端逐页重设计，第 3 阶段

## 目标

把小游戏目录、浏览器小游戏和独立大型游戏的页面外壳统一到主站紫色品牌与一致的导航、文字、控件和间距。游戏画布、棋盘、操作方式、HUD 数据、关卡表现与游戏自身配色继续服务各自玩法。

## 页面范围

- `/games` 游戏目录，包含现有 10 个游戏入口。
- `/games/2048`、`/games/memory`、`/games/breakout`、`/games/snake`、`/games/gomoku`、`/games/flight`、`/games/never-retreat`。
- `/games/ironfront`、`/games/tank-air-war`、`/games/yiren-buche` 三个独立大型游戏。

## 视觉方向

- 游戏目录采用清晰、轻快的游乐场目录：保留现有精选次序与卡片信息，用网格、留白和清楚的游戏类型标签区分入口。
- 浏览器小游戏保持各自棋盘和场景的辨识度；统一页面标题、返回路径、说明文字、设置/成绩面板和触控按钮的视觉尺度。
- 独立游戏优先保证全屏/主玩法沉浸感；主菜单、设置、战绩和暂停层沿用各自现有布局，只调整品牌色映射、容器、边框、文字层级和按钮样式。
- 继续使用设计系统已有色彩、字体、焦点、浅色/深色主题和 reduced-motion 支持。不得把紫色强行覆盖到游戏棋盘/画面上。

## 功能边界

- 保留全部公开 URL、游戏次序、文案信息、排行榜/本地最高分、游戏状态、暂停、重新开始、键盘与触屏控制。
- 不改游戏算法、核心模块、画布绘制、帧率/碰撞/计分、存储结构、第三方 vendor 文件、关卡与素材加载路径。
- 以 HTML/CSS 为主；仅在改善无障碍语义或外壳布局确有必要时添加包装类，不改业务钩子与交互事件目标。

## 验收标准

- 目录在桌面、平板和手机下保留所有 10 个游戏入口，精选游戏和标准卡片层级清楚。
- 7 个浏览器小游戏与 3 个独立大型游戏都保留玩法画布/棋盘和现有控制，导航、标题、面板、按钮体现统一品牌。
- 游戏专属对比色与主题可读；窄屏游戏 HUD、触控区域和菜单动作不被挤压。
- 以浏览器截图完成代表页面视觉检查，不运行自动化测试、不做生产发布。
