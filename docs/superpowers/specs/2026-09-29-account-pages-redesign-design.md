# 账号页与个人中心重设计

日期：2026-09-29  
状态：按已确认的全用户端重设计范围实施  
所属项目：用户端前端逐页重设计，第 4 阶段

## 目标

让登录、注册、管理认证和个人中心沿用主站的紫色品牌与统一控件，同时让账号操作更紧凑、个人数据更容易浏览。保留现有认证流程、表单字段、动态状态和服务端交互。

## 页面范围

- `auth.html` 的登录与注册状态。
- `auth.html` 的管理员认证状态与登录后的个人中心状态。
- 用户个人内容分页签、活动列表、注销确认流程。
- `/admin` 管理后台本身不在用户端页面重设计范围内，继续使用独立工作台外壳。

## 视觉方向

- 共享页面底色、表面、边框、焦点环、字体和品牌动作使用 `design-system.css` 令牌。
- 登录/注册使用窄幅居中卡片，表单输入区和提交动作保持清楚的上下层级。
- 个人中心使用较宽内容卡；桌面展示六项概览与并列快捷入口，手机改为三列数据、单列快捷入口与三列分页签。
- 管理认证继续使用现有独立说明和令牌字段，注销动作保留危险操作的语义色。
- 兼容主题图标 CDN 不可用的预览状态：快捷入口标题和说明不能依赖图标节点来确定网格位置。

## 功能边界

- 不改认证、个人数据、退出、管理员权限、重定向或账号注销 JavaScript 流程。
- 保留所有字段名、输入类型、校验约束、ID、ARIA、`hidden` 状态和链接目标。
- 不改变后台页面，不新增接口、依赖、公开路由或账户能力。
- 通过本地浏览器画面检查，不运行自动化测试、不发布生产。

## 验收标准

- 登录、注册、管理员认证和个人中心均保持原有内容与控件，窄屏不会横向溢出。
- 个人数据与分页签桌面/手机重排清晰；外部图标缺失时快捷入口文字仍正常横排。
- 表单焦点、主要动作、退出和注销确认层级可辨，深浅主题继续沿用共享令牌。
- 不伪造本地静态预览无法提供的认证状态或账号数据。
