# 分享链接提取

已确认范围：粘贴抖音或小红书分享文案/链接，获取视频、视频音频、帖子标题正文和封面。文案不包含语音转写。提取源文件，不承诺移除烧录水印。

本机版本采用已启用的 Chrome 调试连接，只打开本次任务的新后台标签，监听对应作品详情响应，结束关闭该标签。不导出 Cookie，不操作已有标签。公网 API、付费解析服务和自建无登录浏览器是后续部署选项；本次无新增第三方账号或付费服务，解析接口仅限回环访问且需环境变量显式启用。

原生页面复用工具站样式；四类结果分别展示，缺少资源明确显示不可用。视频播放源优先完整 H.264 MP4；音频优先下载同一视频的独立音轨，缺少独立音轨时从完整视频导出 MP3。下载请求使用短期随机票据，服务端只访问允许的媒体域名，逐跳校验及固定公网 DNS 地址；禁止任意 URL 代理。原生 FFmpeg 只读取本地下载文件，不接收远程播放列表。

输入最多 8000 字，单次一条链接；解析并发 1、每分钟 5 次；临时票据 20 分钟；下载最多 1GiB，音频任务一次一个、最多 10 分钟。取消客户端请求后终止下载和转码并清理临时文件。小红书仅按目标 note ID 匹配数据，待实际链接验证，不宣称已实测。

验收：URL 白名单、目标 ID、解析、缺失资源及 SSRF 测试；真实抖音链接解析文案/封面/视频文件头；本地带音轨素材验证音频导出；界面、错误反馈及全部既有测试。
