# AI 生图导航与占位页设计

## 目标

在全站主导航增加“AI 生图”入口，并创建可公开访问的 `/image-generation` 占位页，为后续接入 GPT 图片生成 API 保留稳定地址和页面结构。

## 页面与导航

- 导航名称固定为“AI 生图”。
- 地址固定为 `/image-generation`。
- 桌面导航中位于“视频模型价格”之后、“小工具”之前；没有“视频模型价格”的页面同样将它放在“资讯”之后、“小工具”之前。
- 占位页中该导航项显示激活状态，并保留 Logo、我的收藏、明暗主题和移动端菜单。
- 全站现有静态页面及客户端生成的导航统一增加此入口，避免不同页面显示不同菜单。

## 占位页

- 使用现有紫色大卡片视觉体系，页面保持宽松、居中。
- 主标题为“AI 生图”，说明后续将接入 GPT 图片生成 API。
- 展示“提示词创作、参考图编辑、多尺寸输出”三项未来能力，只作为预告，不提供不可用的输入框或生成按钮。
- 提供返回工具库和浏览小工具两个真实可用入口。
- 设置页面标题、描述、canonical、favicon，并加入站点地图。

## 服务端与未来扩展

- 服务端将 `/image-generation` 映射到独立静态 HTML。
- 本次不保存提示词、不上传图片、不调用任何外部 API，也不配置 API 密钥。
- 后续接入 GPT 图片生成 API 时沿用该 URL，在页面内替换占位主体，不需要再次修改导航链接。

## 响应式与无障碍

- 桌面端为宽松的大卡片布局，手机端收敛为单列。
- 所有链接支持键盘聚焦；装饰图形不进入辅助技术的阅读顺序。
- 页面不得产生横向滚动，导航在现有折叠断点正常进入移动菜单。

## 验收标准

- `/image-generation` 返回 HTTP 200，并包含“AI 生图”与“即将上线”的明确说明。
- 全站主导航及移动菜单存在且只存在一个 `/image-generation` 入口。
- 占位页没有图片上传、生成请求或外部 API 调用。
- 首页站点地图包含该 URL。
- 本地完整测试、生产发布测试与线上源站验证全部通过。
