# 微信原生工程浏览器模拟预览

用户已在说明默认手机预览、交互、本地存储、源码切换和真实微信能力边界后回复“补上吧”，按此已授权设计实施。

复用现有独立项目域名及 CSP 的预览服务，在服务端把原生工程包装成临时 web 模拟作品；不修改原始工程、导出内容或微信验证状态。模拟器不申请 AppID，不调用模型，不改变计费。若独立预览不可用则显示原因并保留源码和导出。

默认手机预览，可切换源码。模拟 WXML 常用布局、表达式、条件、循环、输入/点击事件、Page.setData、生命周期、同步/异步本地存储、导航和提示。存储保存在当前项目隔离域名，使用模拟器专用键。微信服务、权限、支付等不模拟成功，显示不支持提示。自定义组件等无法完整还原的结构明确显示模拟限制，不宣称微信编译或真机通过。

生成代码只在独立项目域 iframe 内执行。主站仅展示源码文本和预览 URL；沿用鉴权、所有权、速率限制、过期令牌和禁止网络的 CSP。模块封装为静态函数，不启用 unsafe-eval。预览包装大小超限时明确失败，不修改原生源码。

验收：真实浏览器验证计数、输入、循环、条件、存储刷新、多页导航及源码切换；验证不支持能力提示和网络隔离；回归原生导出、目标隔离与网页预览。
