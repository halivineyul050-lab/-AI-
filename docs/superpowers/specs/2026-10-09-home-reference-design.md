# 首页参考图改版

用户提供的参考图是本次视觉依据。保留泥壳 AI 品牌、真实内容与已有搜索、收藏、对比、工具详情功能。

桌面：内容宽度 1360px，浅紫白背景，紧凑导航；双栏首屏，左侧黑紫标题及搜索、热门词，右侧倾斜的欢迎与真实统计面板及透明机器人插画。首屏下方七项快捷入口，四列资讯卡，五列横向工具卡。取消旧的不规则卡片及信任带占位。

移动端：单列首屏，缩小插画；快捷入口横向滚动；资讯和工具卡按可用宽度布局，避免横向页面溢出。保留深色主题、键盘可达、减少动画偏好。

内容差异：品牌沿用泥壳 AI；不使用截图中虚构的工具数量、新闻标题和浏览量。沿用当前生产的最新资讯列表，按发布日期取四张卡片，无内容时显示空状态。分类和按钮指向现有功能。

验证：参考图原尺寸 1672×941、1366px 桌面、390px 和 375px 手机；检查搜索结果、快捷分类、工具详情、收藏、对比、资讯详情、主题及无内容状态。只修改首页相关文件，不覆盖工作区已有其他改动。用户随后授权生产发布，按 docs/production-release.md 制作完整候选并单独记录发布结果。
