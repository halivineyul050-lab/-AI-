# 图片物体消除

用户已批准自建模型优先的方案。新增 `/utilities/image-erase`，在现有工具站上传图片、涂抹需要消除的内容、自动补全背景，预览并下载 PNG。

交互：画笔、矩形、选区橡皮擦；笔刷大小；撤销、重做、清空；处理前后比较；连续消除及恢复原图。沿用绿色工具站样式，大画布、右侧控制面板。文件选择不设置 accept 筛选，读取时验证图片。支持 JPEG、PNG、WebP、BMP，原文件不超过 20MiB，工作图最长边 2048px、最多 4Mi 像素；缩小后明确显示输出尺寸。

Node 同源接口接收当前工作图与黑白选区 PNG，运行独立 Python CPU 子进程调用 LaMa TorchScript 模型。每次至多一个任务，超过容量返回可重试错误。后台限制编码输入、像素、执行时间；图片只在临时目录处理，完成、失败或取消均清理；模型和依赖独立部署，不依赖开发电脑。仅对选区内像素合成修复结果，未选区像素保持一致。CPU 推理最长边 512px，带上下文局部裁切后回贴；复杂背景效果以实测为准。

接口：GET `/api/utilities/image-erase/status` → `{data:{enabled,maxDimension:2048}}`；POST `/api/utilities/image-erase` JSON `{image:PNG数据URL,mask:PNG数据URL}` → `image/png`；错误沿用 `{code,title,status}`。请求可取消；服务端仅处理本地模型路径，无第三方图片发送。

验收：算法验证选区外逐像素不变、空/全选及不匹配选区被拒绝、透明度保留；接口验证大小、并发、超时及取消清理；浏览器实际选图、画选区、撤销、消除、对比、下载。服务器实测内存和速度，再部署到现有源站；公网域名的既有备案拦截另行明确，不声称该问题已解决。
