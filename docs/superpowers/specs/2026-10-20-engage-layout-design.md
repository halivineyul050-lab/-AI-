# 首页参与进来区域样式修复

用户指出截图布局问题，并明确选择“整个区域都整理一下”。

根因：三列网格随订阅卡片拉伸，订阅表单所有控件纵排，前两张卡按钮没有底部布局约束，导致不必要高度与空白。保留原紫色主题、文案、交互和表单语义。

方案：减少卡片内边距与额外段落间距；桌面邮箱和订阅按钮同排，隐私同意独占下一行，前三个操作按钮对齐；721–991宽度采用两列，订阅跨列；720以下单列，360以下表单按钮另起一行。保留原焦点、必填和隐私链接。

范围：只改变 site-catalog.css 的参与区域块以及 styles.css/index.html 缓存版本。生产以线上当前完整快照为基底，不使用整个脏工作区。

验证：Chrome实测1440/1024/768/720/390/320宽度无横向溢出、邮箱可用，桌面按钮差小于1像素；截图人工检查通过。完整预检与线上验证结果以发布记录为准。
