# 全站品牌 Logo 替换设计

日期：2026-09-16

## 目标

使用用户提供的猫咪火炬 PNG 作为泥壳 AI 工具站的新品牌 Logo，并统一更新导航栏、浏览器标签、移动端应用图标、SEO 品牌图和默认品牌占位图。

## 图像处理

以原始 PNG 为唯一视觉来源，不重绘、不改变猫咪、火炬、围巾或圆形深色背景。保留透明通道和正方形构图，按高质量缩放导出：

- `brand-icon-192.png`：192×192，供导航栏、favicon、SEO 和默认占位使用。
- `brand-icon-512.png`：512×512，供 Web App Manifest 和高分辨率设备使用。

导出图应保持 PNG 格式，并验证尺寸、透明通道和文件签名。

## 网站接入

继续使用现有 `/brand-icon-192.png` 路径，从而覆盖所有已有静态页面与服务端生成页面。更新 `manifest.webmanifest`，加入 192×192 和 512×512 图标。对页面中的品牌图标引用增加统一版本参数，避免浏览器继续显示旧缓存。

导航栏结构、品牌文字、图片显示尺寸和页面布局保持现状。

## 验证与发布

发布前验证图标尺寸、Manifest 配置、静态资源响应类型和主要页面引用；运行完整测试并在浏览器检查导航栏和 favicon。发布使用现有生产发布脚本，并在线核对 Logo 文件哈希、主要页面、Manifest、服务状态和健康检查。
