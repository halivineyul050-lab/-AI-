# 后台模型发现

用户已批准：后台所有同类配置统一通过服务地址与密钥获取模型后下拉选择。覆盖小助手、讲解、NeStudio、Skills、资讯摘要及图片平台/模型。

聊天接口接受 HTTPS 根地址、带前缀的 /v1 或完整聊天接口，推导同前缀 /v1/models。管理员接口代理请求，复用 DNS/内网/重定向保护，限制超时与响应大小。只返回模型 ID，不回传密钥或上游错误正文。保存密钥仅在服务地址一致时复用；更换服务地址必须输入新密钥。

前端在地址/密钥填写完成后自动加载，可刷新；保留已保存模型，不自动更换已选模型；地址或密钥变化使旧请求失效。失败不清除配置并说明重试原因。继承模式不加载独立模型。图片模型沿用已有发现和导入能力，新增/编辑模型也提供下拉。

验证涵盖路径推导、权限、密钥复用边界、响应限制、失败提示、旧请求失效、各入口集成。当前工作区有大量既存变更，本次仅记录并修改相关文件，不整体提交或发布。
