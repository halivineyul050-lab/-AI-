# 图片、视频与实用工具页创作工作台重设计

日期：2026-09-29  
状态：第 2 阶段实施完成；后续游戏与账号页面组继续推进
所属项目：用户端前端逐页重设计，第 2 阶段

## 目标

逐页重设计图片、视频和实用工具页面，沿用主站确认的品牌紫与中性底色，令输入、处理状态、预览和导出形成清楚的创作工作流。保留每个工具真实存在的差异，不把本地编辑、服务器 AI 处理、视频编码和资讯查询拼成同一个模板。

## 页面范围

- `/utilities`：实用工具目录
- `/image-generation`：AI 生图创作台
- `/utilities/image-edit`、`/utilities/image-background`、`/utilities/image-enhance`、`/utilities/image-erase`
- `/utilities/video-crop`、`/utilities/video-to-gif`、`/utilities/video-mask`、`/video-pricing`
- `/utilities/link-extract`

## 视觉方向

- 采用克制的创作工作台：页面背景和控制面板使用设计系统表面；大面积预览区清楚、安静，让用户的图片或视频成为视觉焦点。
- 桌面端按任务安排预览与设置的相对位置；标题、隐私/处理方式提示、导入入口和主要导出操作使用一致层级。手机端改为可顺序完成的单栏流程，主要动作易触达。
- 品牌紫用于主要动作、当前选中、可交互焦点和少量关键标记。状态色继续表达成功、警告和错误，不用品牌色替代。
- 继续使用 `public/design-system.css` 中的字体、色彩、圆角、阴影和控件变量，不添加新字体、框架、运行时依赖或远程图片。
- 预览画布可使用浅色棋盘格表达透明区域；其余普通面板保持中性，避免重复的大面积渐变、过重阴影和装饰图案。

## 结构与功能边界

- 图片编辑、视频裁剪、GIF 转换和视频遮挡继续按其独立输入、预览、参数、进度、取消、错误和导出流程呈现。
- 本地处理页面清楚说明文件在浏览器本地处理；服务器 AI 工具清楚说明处理方式与实际可用状态；外部链接提取页保留来源、登录提示和可获取结果信息。
- AI 生图保留生成/历史切换、参考图、提示词、参数、生成状态、演示结果、下载和画布入口。
- 视频价格页保留模型筛选、对比、导出和打印行为；不把价格表改成不便横向比较的装饰卡片。
- 游戏画布、游戏目录、账号与运营后台属于后续阶段，不在本阶段改动。

## 实现边界

- 主要改动落在 `public/utility-theme.css`、各图片/视频/实用工具样式表，以及确有语义需要时的工具页 HTML。
- 不改 `public/app.js`、页面业务脚本、Worker、核心算法、API、表单字段、公开地址、元素 ID、`data-*` 业务钩子或用户文件处理边界。
- 保留浅色/深色主题、移动导航、键盘焦点、reduced-motion 和现有静态导航生成结构。
- 工作区含大量既存改动；不暂存、回退、格式化或覆盖无关文件。
- 按用户要求不运行自动化测试、不发布生产。

## 验收标准

- 实用工具目录能快速区分图片、视频和其他处理工具，并保留现有路由与导航。
- 图片、视频工作页在桌面、平板、390px 手机宽度下层级清楚；上传、画布/预览、状态、参数和主要操作不被挤压或遮挡。
- 透明预览、长文件名、加载/处理中/失败状态、结果区和窄屏表单仍有合适的呈现方式。
- 深浅主题均可读，页面无非预期的横向溢出；脚本选择器与原业务流程保持原样。
- 完成代表性页面的浏览器视觉检查；不把静态回退数据冒充为线上 API 结果。
