# 主站内容视图编辑式重设计

日期：2026-09-29
状态：第 1 阶段实施完成；后续页面组待继续
所属项目：用户端前端逐页重设计，第 1 阶段

## 目标

重设计主站首页与共用内容视图，使其更像一份便于检索和比较的 AI 工具目录：页面层级清楚，首页搜索与精选内容更早进入视野，内容页有一致的标题、筛选和卡片节奏。继续使用原生 HTML、CSS 和 JavaScript，不改变已有功能和公开地址。

用户已选择“编辑式工具目录”方向。保留泥壳现有紫色品牌识别，以清爽中性的页面底色、克制的品牌强调、清楚的排版和更紧凑的内容编排取代大块渐变与重复留白。

## 页面范围

### 本阶段包含

所有由 `public/index.html` 和 `public/app.js` 提供的主站视图：

- 工具库首页 `/`、发现 `/discover`、收藏 `/favorites`、教程 `/guides`、榜单 `/rankings`、工具对比 `/compare`、教程目录 `/tutorials`、资讯 `/news`
- 分类页 `/category/:slug`
- 广告合作 `/advertise`、关于我们 `/about`、收录标准 `/standards`、用户协议 `/terms`、隐私政策 `/privacy`、法律声明 `/legal` 和问题反馈 `/feedback`

这些路径继续由现有静态入口和客户端视图切换处理；路由、导航项及页面文案含义不因视觉改造而改变。

### 后续阶段

本次用户请求的完整重设计按独立页面组推进：

1. 主站首页与内容视图（本设计稿）
2. 图片、视频和其他工具页
3. 游戏目录与游戏外壳
4. 账号页

运营后台不在本次已确认范围内，继续保留工作台布局。大型独立游戏继续保留各自的玩法画布、HUD 和交互设计。

## 视觉与布局

### 全站主站外壳

- 保留现有品牌标识、紫色主色、浅色/深色主题和站点导航内容。
- 统一主站 header、侧栏、正文栏宽、标题字号、分区间距、卡片边框与操作控件的层级。
- 正文沿用现有约 1200px 内容宽度；导航继续在宽屏下保持完整，在窄屏下使用现有移动菜单交互。
- 背景、边框和阴影以清楚的层级为主，不依赖大面积渐变区分普通内容块。

### 首页首屏

- 把现有居中单列 Hero 改为桌面两栏的编辑式目录入口：主栏放置主标题、说明、搜索框与热门任务；侧栏放工具数量、分类数量和核验提示。
- 减少 Hero 的纵向占用，使精选工具标题在常见桌面首屏更早出现；保留当前三个信任说明，但与 Hero 和精选内容建立紧凑的网格关系。
- 移动端收为单列，搜索输入和提交按钮保持易触达，热门任务允许换行。
- 工具总量、分类统计、热门搜索及精选工具仍使用现有数据和交互，不引入新的数据源。

### 内容视图

- 为工具库、发现、榜单、教程、资讯、分类、收藏、对比和说明页建立共用的标题区、辅助说明、页面操作区和统一间距尺度。
- 卡片、筛选项、输入框、标签和按钮采用一致的颜色、边框、圆角、焦点及悬停规则。
- 保留各视图为其内容服务的结构：资讯仍可使用编辑式文章列表，政策页保留目录，反馈页保留说明与表单，工具目录保留筛选和不同浏览模式。
- 不为追求视觉一致而把不同信息类型改成相同卡片，也不删除现有说明、状态提示或内容。

### 交互与无障碍

- 搜索、分类筛选、排序、收藏、比较、视图切换、导航、提交反馈和浏览器历史行为保持不变。
- 主内容跳转链接只在键盘聚焦时显示；修整其定位和外观，使它明显、可操作且不覆盖主要导航。鼠标操作和触屏操作不应持续显示该链接。
- 保留可见键盘焦点、语义标题结构、现有 ARIA 标签与 reduced-motion 支持。
- 轻/深色主题均消费 `public/design-system.css` 的公共变量，不在主站页面样式里另造一套色彩 token。

## 实现边界

- 主要改动位于 `public/design-system.css` 与 `public/assets/css/site/` 的主站样式模块；只在布局或语义确有需要时调整 `public/index.html`。
- 尽量不改 `public/app.js`。如需调整 DOM，必须保留所有业务选择器、`data-view`/`data-view-link` 钩子、表单字段名、ARIA 状态和事件目标。
- 不新增前端框架、构建步骤、依赖、公开路由或后端接口。
- 本阶段不重写工具页、游戏、账号或后台；这些页面组遵循本阶段确认的视觉语言，各自另行设计和实施。
- 工作区当前有大量既存改动。只修改与本阶段有关的文件，不回退、格式化或提交其他既存改动。

## 验收标准

- 首页首屏清晰呈现搜索入口、热门任务、目录规模和可信信息；桌面版减少 Hero 空耗，精选工具区域更早进入阅读顺序。
- 主站所有视图共享同一标题层级、内容宽度、间距、卡片和控件语言，同时保留各视图有意义的结构差异。
- 桌面、平板和手机宽度下，导航、卡片、筛选和表单均可使用，不出现横向溢出或内容遮挡。
- 浅色与深色主题一致；键盘焦点明确；主内容跳转链接仅在聚焦时出现。
- 搜索、筛选、排序、收藏、比较、路由、表单与导航行为及其既有 DOM 契约保持不变。

## 自检

- 范围仅包括主站 SPA 及其静态内容视图，工具、游戏、账号和后台均被明确排除或安排到后续阶段。
- 视觉方向、响应式行为、主题支持、交互保留要求与文件边界一致。
- 没有“待定”要求；新增布局不得以重写业务逻辑为前提。
