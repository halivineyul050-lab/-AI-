# NeStudio 模型输出修正

本次属于已授权上线任务的缺陷修复，继续开发、测试并发布。

线上失败任务的计划已拆成四文件，但第一个 index.html 连续两次长度截断且没有保存文件。代码把单文件上限固定为 6000，而配置为 16009。真实模型探测进一步确认：即使提供 16009，DeepSeek flash 仍将全部 completion tokens 用于 reasoning，正文为空。因此单纯放大输出上限无法解决问题。

修正：已知支持关闭思考的 DeepSeek flash/v4-flash/v4-pro/chat 请求显式 thinking.type=disabled；不改其他模型参数。文件输出使用配置上限，仍经钱包预算裁剪、用量累计、请求次数和时限约束。真实模型关闭思考后可完整返回正文，但将长源码放进 JSON 字符串会产生无效转义，因此规划继续用 JSON，文件改用原文协议：首行 `<<<FILE>>>` 后接本次请求路径，末行 `<<<END_FILE>>>`。兼容不带路径的首行与旧 JSON 文件协议；存在路径时必须精确匹配。缺结束标记、length、语法错误或大小超限均不能保存，不拼接截断片段。

验收：新增回归先红后绿，覆盖配置上限、钱包裁剪、思考耗尽输出、原文引号/换行、缺结束标记、错误文件名。保留完整文件检查、检查点、计费和真实浏览器验收。使用线上当前真实模型与失败任务的已存规划在隔离预览内验证，不修改失败任务或用户积分，不保存或打印密钥。正式发布必须以当前线上完整版本为基底，仅叠加本次审阅文件，按 production-release.md 执行。
