# 命名模型配置库

用户明确要求：系统模型配置可保存多套命名方案，方便以后切换和跨模块复用。

配置包含名称、兼容类型、HTTPS接口、聊天模型名、服务端加密KEY；图片平台方案不绑定具体模型，仍沿用平台下的模型管理。小助手、交互讲解、NeStudio共享chat方案；图片仅选image方案。前端只拿metadata和profileId，绝不回传明文KEY或写localStorage。

管理员在原表单填写后“保存当前为方案”；KEY留空时可复制同地址已保存活动KEY，或选中方案另存。不允许同名覆盖，最多100套。列表提供刷新、选用、二次删除确认；选用只填表单并保留引用，必须点击模块原保存按钮才生效。改地址、新KEY、清密钥、继承切换、重新加载自动清引用。删除方案不影响活动配置副本。

安全：库CRUD和引用只允许超级管理员，使用既有cookie同源保护；chat/image隔离，应用/源KEY复制必须接口规范化一致；沿用AES-256-GCM和服务器现有主密钥。验证和上游SSRF/跨域重定向控制保留。

实现：model_profiles独立表，SQLite/MariaDB042兼容迁移、独立store、受保护API、共享前端组件与四处接入。无自动迁移真实KEY至库、无明文导出、无自动切换、不修改现有KEY。

验收：单测落盘加密/重开持久化/脱敏/上限/删除；API超管授权/CSRF/错误host与类型拒绝/3模块KEY复制/图片与discovery；浏览器选用/另存/失效/删除确认；新线上基底完整检查、既有生产脚本发布、私有API与迁移和原服务健康验证。
