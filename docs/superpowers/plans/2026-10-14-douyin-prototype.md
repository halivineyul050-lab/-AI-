# 抖音解析 Implementation Plan

> 使用 executing-plans，当前会话顺序执行。

**Goal:** 验证可自建的抖音单视频解析，并形成可用且有边界的站内原型。
**Architecture:** 新 douyin-public 模块使用独立匿名 Chromium 读取指定公开视频的正常响应；douyin-proxy 将实际出站连接绑定核验后的公网 IPv4；已有 link-extract 包装账号绑定的临时下载结果，保留本机模式。
**Constraints:** 不绕过平台登录或验证，不依赖个人浏览器登录态做线上服务；生产基底完整包；真实链接验收前关闭线上入口。

- [x] 对比匿名移动/桌面/服务器样本响应，记录能力边界。
- [x] 安全匿名浏览器解析器：精确作品 ID、独立上下文、浏览器沙箱、受控出站代理、拒绝外域与私网重定向。
- [x] 服务与下载权限：原型独立开关、限流并发、临时票据、资源校验，保留本机模式。
- [x] 页面：粘贴/取消、视频封面文案与错误状态、原型未启用时诚实禁用。
- [x] 自动测试/浏览器验收/真实样本媒体字节验证；按正式发布脚本上线，并完成真实HTTPS页面播放、完整下载、封面及文案验收。
