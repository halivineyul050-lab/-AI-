# NeStdutio 第三阶段实施计划

> 使用 writing-plans 编写，executing-plans 在本会话逐项执行；已批准规格见 2026-10-15-nestdutio-design.md，不重复产品审批，实现任务不启用子代理；发布前按 requesting-code-review 技能安排只读安全审阅。

**目标：** 完成规格第三阶段的真实数据收集、作者管理、独立后端交付和自定义域名；不能把静态首版当完整交付。

**实现边界：** 继续使用固定 Node 运行时，不执行模型生成的后端。作品通过同源 SDK 提交声明式表单；作者数据接口仅在主站鉴权。预览和浏览器检查写入独立临时集合，不污染真实记录。发布仍使用当前生产完整基底与 release-production.sh。

## 任务与验收

- [x] 035 迁移及 `form-schema.mjs`、`forms.mjs`：声明字段校验、幂等真实入库、配额、作者跨设备读取/分页/导出；红测跨作品、跨账号、匿名读取、未知字段、重复请求不同内容、更新字段后保留历史记录。
- [x] `form-runtime.mjs`、preview/publications 集成：同源且无主站 Cookie 的 SDK；严格 JSON/来源/体积/速率；公开端只有写入，没有管理读取。草稿/候选不写正式数据，下线停止写入。浏览器真实提交验收，不接受只改成功文案。
- [x] 生成协议增加 forms、fill 和 submitForm 固定验收类型；模型生成前冻结表单声明，自动修复不允许改变它。后台/工作台显示真实数据方式并提供作者数据抽屉与 CSV 导出。
- [x] 独立导出：复用固定表单校验与 SDK，附 Node 22 SQLite 运行时、空数据库、启动说明、作者初始化认证。无默认口令、不含线上记录/平台秘密；干净解压目录验证提交、作者鉴权、重启持久化。
- [ ] 自定义域名：声明/唯一性/所有权 TXT/解析核验、绑定状态与解绑；未完成 HTTPS 检查不显示上线。受控证书和 Nginx 配置器与主站源文件隔离，不允许任意命令/路径；自动化前复核现有基础设施。测试域名劫持、未验证/失效状态和解绑。
- [ ] 浏览器桌面/手机：真实报名、跨设备作者记录、导出、模型生成与继续修改保留表单、独立包；完整本地和服务器测试后通过正式发布脚本发布，公网验证并记录备份和限制。

域名需要作品作者提供并配置其域名 DNS，系统必须给出真实待配置状态。平台已有 apps/preview 通配证书不能冒充任意自定义域名证书。
