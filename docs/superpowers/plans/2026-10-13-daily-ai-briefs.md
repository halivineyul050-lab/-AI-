# 每日快讯 Implementation Plan

> 使用 executing-plans，当前会话顺序实施。

**Goal:** 每日搜索、核验并自动发布简短AI快讯及可用配图。
**Architecture:** news-briefing.mjs负责可信来源和原文/图片补全；news-sync负责去重、中文摘要、日频调度与发布；数据库migration31存封面；admin-news-sync提供日频与结果说明。
**Constraints:** 生产基底完整包，仅审阅文件；不输出密钥，保留现有模型配置；安全DNS校验、3次重定向、图片2MB。仅站内自动发布。

- [x] 来源与原文核验：官方RSS+AI HOT关键词搜索、近期消息、可信域与传闻过滤。
- [x] 图片解析及存储：RSS/OG字段，安全二进制下载，migration31，公开只读同源封面接口。
- [x] 日频与发布：默认每日/12条，重启保留日频；候选去重在模型前；80–150字中文目标摘要；失败降级。
- [x] 后台：日频选项、清晰保存提示、已发布数/图片结果/可读错误；统一原后台样式。
- [x] 功能和安全测试、全套检查、隔离真实采集预演、白名单完整包发布、真实页面/API检查、记录清理。
