# 生图积分实施计划

已确认设计：登录后生成，默认 20 积分/张；邮箱验证后一次赠 60；套餐 6元600、18元2000、50元6000、100元12500。微信/支付宝暂未开放，兑换码可充值。后台可修改模型积分、套餐及管理兑换码。

架构：积分账户、不可变流水、生成预留订单和单次兑换码通过同步数据库事务操作；SQLite 与 MariaDB 均有迁移。服务端原子冻结积分，成功结算实际张数，失败返还；兑换码只保存摘要，原码仅在创建时返回。生成重启未确定结果的冻结记录不自动退款，后台可核查后处理。赠送领取必须邮箱验证，超级管理员可用相同规则但免验证不等于已验证。
