# NeStudio 历史项目实施计划

Goal：项目抽屉管理和服务端聊天历史。
Architecture：复用任务表生成稳定聊天轮次，新增独立项目归档元数据表；项目列表分页、搜索，账号隔离。原API列表兼容保留。

- [x] 基底：核对生产版本，隔离完整包，记录SHA。
- [x] 服务端：先测试历史分页/归属/状态，再实现projects.history、browse、rename/archive接口与双数据库039迁移。
- [x] 前端：历史抽屉、搜索/分页/归档恢复/重命名，加载聊天、运行任务恢复、草稿隔离，确保切换竞态保护。
- [x] 验证：接口与浏览器回归、全量测试、语法与logo、代码审查。
- [x] 上线：正式发布脚本、健康与真实公网验证、记录发布与备份。
