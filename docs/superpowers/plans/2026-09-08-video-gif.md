# 视频转 GIF Implementation Plan

**Goal:** 完成已批准的站内本地视频转 GIF 工具。

**Architecture:** 独立原生 HTML/CSS 页面，video + canvas 解码取帧，模块 Worker 使用本地 gifenc 编码。沿用 Node 静态白名单和现有主导航。

**Tech Stack:** 原生 JS、Web Worker、gifenc 1.0.3、Node test runner。

## Constraints
不上传视频；200MiB 输入；30秒源片段；720px 最大边长；600帧和120M累计像素预算；输入异常和取消可恢复。

## Verification evidence
2026-09-08: npm test 52/52 passing; git diff --check clean. Generated 3s H.264 test video using FFmpeg; real in-app Chromium browser converted it successfully. Trim 1..3 seconds at 2x generated a 320x180 GIF with 10 distinct frames, 1.000s duration and infinite looping, independently decoded using ffprobe and Pillow. Verified cancel then retry, corrupt MP4 error, desktop and 390px mobile layouts. No conversion console errors. Reviewer identified an in-flight seek shortcut; fixed to wait for seek completion before capture.

Download link is implemented using an image/gif Blob URL and the download attribute. The in-app browser's download event timed out, so filesystem download was not confirmed there. For independent decoder inspection only, a temporary browser hook captured the generated Blob with FileReader; it was removed by reload. No inspection hook exists in production code. Physical iOS/Android devices were not tested.
