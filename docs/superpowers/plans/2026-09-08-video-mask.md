# 视频遮挡 Implementation Plan

**Goal:** 交付用户授权的马赛克/模糊本地视频工具。
**Architecture:** 复用裁剪几何工具；独立表单/预览与Worker；复用已有FFmpeg资产，不新增大依赖。

- [x] 测试先行：validateMask / effectParameters / createMaskCommand，覆盖非法时间、选区溢出、模式/强度、音轨映射和处理范围。
- [x] video-mask-core.js：集中验证、效果参数、过滤器命令。video-mask-worker.js：加载/处理/结果，父页面终止取消。
- [x] video-mask.html/css/js：固定矩形、模式/强度/生效时间、整帧效果预览、进度取消与导出。
- [x] 工具索引/静态路由/安全策略/站点地图接入；保持旧工具可用。
- [x] 浏览器实测两种输出，独立音轨/帧内容校验，手机布局与错误恢复；运行全部测试，更新说明。

验收记录：2026-09-08 全套 npm test 65/65 通过。浏览器两种模式均成功导出；独立 ffprobe 与逐帧比对确认 320×180、3 秒、音轨保留及 [1,2) 局部生效。取消后重试成功；无效时间禁止导出；损坏 MP4 显示错误。390px 手机布局已截图检查。审查发现并修复视频独立重置时间戳导致音画偏移，带时间偏移素材重新校验通过。
