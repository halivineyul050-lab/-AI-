# NeStdutio 数据应用与自定义域名

作品支持静态网页、浏览器本地存储及声明式表单。表单字段由固定运行时验证并入库；作者在工作台“数据”查看、分页、下载 CSV。公开作品只提供提交接口，没有公开记录查询接口。预览及发布候选测试记录与正式记录分离。

带表单的源码 ZIP 包含前端源文件、固定 Node 22.13+ SQLite 后端及作者认证初始化命令。解压后先运行 `node server.mjs --init-admin`，再运行 `node server.mjs`。不需要 npm install；作者界面默认仅监听本机 8081，公开端默认 8080。具体 HTTPS、PUBLIC_ORIGIN 和 SSH 隧道说明见包内 README。导出不包含线上数据、平台凭据或默认作者密码。

自定义域名需先发布作品，再添加自有域名。按界面添加 A/AAAA 与 `_nestdutio` TXT 记录，所有 IP 必须指向本服务器；平台主站和 apps/preview 保留地址不能绑定。完成 DNS 所有权检查后，由独立 root 管理的证书任务申请证书并验证 HTTPS 返回当前发布版本，才显示可访问状态。每个作品一个绑定，当前服务最多 100 个绑定。移除后立即撤销作品路由，基础设施清理失败会重试。

模型生成的后端代码不会被执行。首版不支持访客账号、支付、任意数据库或任意外部 API；表单适用于报名、预约、询价等记录收集。现有 apps/preview 通配证书采用人工 DNS 验证，仍需在到期前人工续期；本阶段新自定义域名通过 HTTP 验证任务定期续期。
