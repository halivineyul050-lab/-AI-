# NeStudio 成本核算与网页质量：第一阶段验收

日期：2026-10-21。状态：本地代码与隔离试跑验证完成，未发布生产。

## 已实现

- SQLite/MariaDB 043 迁移保存逐请求账本；固定收费与 Token 收费都记录上游实际用量。保留并行开发的 042 迁移。
- 正常、截断、JSON 格式回退、HTTP 错误携带 usage、无 usage 与传输异常分别记录。缓存输入、推理输出作为已有总量的子集，不重复相加。
- 人工采购价、币种、缓存价独立于用户积分售价；保存请求价格快照，金额使用定点计算。未知用量/价格不按零成本处理；公共 API 不返回采购价。
- 管理员查看最近任务用量、核算成本和用户扣分；用户查看实际用量与最终扣分。移除把单次输出上限当整项任务价格的误导估算。
- 房贷平台独立核对零利率、非零利率、非法输入；习惯工具验证增加、独立打卡、刷新恢复与删除；报名仍要求真实服务端回执。
- 房贷规划阶段拒绝提前断言计算结果的 fillText 操作，并对明确标记的月供/总利息/还款总额纯数值预期做数学核对。这不是通用需求验证器，后续独立运行检查继续保留。
- 原始文件截断可在受限条件下续写，保留完整结束标记、语法与体积检查。依赖上下文裁剪，已有有效大项目不再因旧100KB门槛拒绝修改，未涉及资源保留。
- 用户注销时清理新账本，兼容生产无外键的 MariaDB。

## 真实模型试跑

用户授权上限5元，前提是先确认供应商单价。只读核验生产接口为 api.deepseek.com、模型 deepseek-flash，余额查询确认账单币种 CNY；未打印、保存或下载接口密钥。采购配置和线上收费均未修改。

官方价格核对来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 。2026-10-21 页面列示 Flash 高峰每百万缓存命中输入0.04元、未命中输入2元、输出8元；空闲时段为一半。本轮使用高峰价且全部输入未命中的保守金额作为预算上界，不能将其当实际账单扣费。

| 试跑 | 结果 | 请求数 | 保守金额上界/元 |
|---|---|---:|---:|
| 首轮三个案例 | 房贷失败、习惯/报名成功 | 9 | 0.162574 |
| 房贷复跑1 | 模型规划月供预期算错，失败 | 4 | 0.122070 |
| 房贷复跑2 | 模型规划总利息预期算错，失败 | 4 | 0.100298 |
| 房贷最终 | 3文件、13项模型验收及3项平台业务检查通过 | 4 | 0.044496 |

## 当前边界

采购成本仍是人工价格快照，不自动处理峰谷、折扣、未来调价或汇率。未知历史用量不补造，已有用户收费不追溯改写。是否调整20积分售价，需要收集更多完整任务和失败成本后再定。

微信原生目标尚未实现。已核对官方工程与 CLI 文档，确认本机开发者工具已安装、当前服务端口未监听；独立目标设计见 `docs/superpowers/specs/2026-10-21-nestdutio-native-miniprogram-design.md`。编译执行端、作者 AppID、模拟器和真机验证必须有真实结果，不能把网页作品当原生小程序完成交付。

本次没有生产发布；后续上线仍必须以当前生产完整版本为基底，按 docs/production-release.md 只叠加经过审阅的本次文件，不能直接打包脏工作区。
