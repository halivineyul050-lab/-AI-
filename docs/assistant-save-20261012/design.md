# 小助手保存反馈修复

原保存处理只将当前配置状态写到顶部，成功时没有“已保存”提示，失败提示也在顶部，按钮附近无结果；等待请求时没有“保存中”文案，浏览器约束校验未触发submit时也没有统一反馈。

保留现有API与字段。在保存按钮旁新增aria-live反馈，显示加载/保存中、明确保存成功和是否启用、服务器错误及字段校验；保存中按钮和重新加载禁用，重复请求被拦截，20秒请求超时后恢复。失败保留输入密钥，成功后清空密钥框。新增四项行为回归，修复前四项失败、修复后四项通过。

浏览器候选服务验证真实PUT保存每日次数，GET重新加载保留值；缺模型服务端422和URL原生校验在footer显示；320/390/1440px反馈区域无溢出。仅使用本地测试管理员与测试数据库。
