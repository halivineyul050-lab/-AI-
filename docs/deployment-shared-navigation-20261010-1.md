## 原因和改动

首页与独立工具、游戏、价格页面使用不同导航模板：菜单顺序、名称、可见入口、品牌布局、账号控件和响应式断点均不一致。现在生成器以首页头部为唯一模板，为 20 个公共入口生成统一导航；独立页面适配各自的跳转和事件绑定。生图、小工具、价格表放在首页已有的“更多”菜单，当前二级页面同时高亮“更多”和对应菜单项。

新增独立页面头部交互和限定在头部内的共享样式，保留搜索、提交工具、收藏、对比、主题、登录头像及账号中心入口。统一手机菜单断点为 1100px。导航图标内嵌，独立页面无需新增第三方图标脚本。服务器静态资源白名单增加两个共享资源；本次未修改账号权限、数据库或生成图片功能。

完整生产快照仅叠加本次审阅的 31 个文件，共 629 个文件。上传包 SHA-256：`52292e1b66cd2306ef0816f23dd4e51b2df83927b3716d5c84ab36131975e298`，上传前后摘要一致；发布后 31 个文件摘要全部与候选清单一致。打包器核实其他文件与生产基底逐字节一致，排除真实环境配置、数据库、用户内容、依赖目录及 Git 元数据，保留 `.env.example`。
