# 交互讲解：Anatomy 接入

2026-10-15 接入交互版；可下载配音视频不在本次范围内。

## 用户功能

/explain 保持自由输入，生成 version 2 结构场景：立体零件、作用说明、参数滑块、部件选择、拆解/合拢、缩放、重置、分步播放/暂停、浏览器朗读。朗读由用户主动开启，使用设备语音服务；没有合成可下载的配音音轨。现有月相/概率/排序案例及 version 1 场景继续可用。

零件支持 box、cylinder、gear、spring、pipe，采用固定绘图适配器和上游等轴测几何库；不是服务器运行任意编程 Agent，也没有接入上游试验性完整3D/WebGL模式。动画与知识内容仍需核验，几何结构可渲染不等于机械配合、科学事实和排版已全部核准。

分享携带经过校验的场景与当前步骤、参数、拆解和缩放；内容较大时明确拒绝链接分享，不截断。最近结果仍保存在本设备，公共电脑使用者需要留意该本地记录。任务私有，恢复前核验服务器属主，不向其他账号展示待恢复问题。

## 模型与额度

运营中心 → 系统配置 → 交互讲解配置。

- 默认显式继承AI小助手模型，继续共享其每日次数；没有自动更换用户的现有接口、模型或密钥。
- 可切换为独立模型，单独配置接口、加密密钥、启停和每日额度。
- 请求等待上限30–180秒，默认120秒；输出上限2000–24000 tokens，默认12000。继承模式也可单独调节这两个资源项。
- 额度锁定到请求等待上限后5秒，成功计一次，失败退回；修正不重复计次。结算跟随原预留来源，配置切换不把旧额度退到另一个功能。

模型密钥仅服务端加密保存。公网配置接口只返回模式、来源、启停、就绪和每日次数，不返回密钥或接口地址。

## 接口与恢复

- GET /api/v1/explain/config：前台状态。
- POST /api/v1/explain/tasks：登录用户提交question/mode/level/requestKey，相同账号与requestKey复用任务。
- GET /api/v1/explain/tasks/:id：仅属主读取状态、结果或安全错误码。
- GET/PUT /api/admin/v1/explainer/provider：管理员配置。
- POST /api/v1/explain/generate：保留同步兼容接口；前台改用持久任务。

任务状态queued/planning/building/checking/repairing/ready/failed；只是实际服务阶段，不是准确进度百分比。页面刷新查询原任务，不重放模型请求。服务重启将未完成任务标记中断并退还其已持久化预留，不自动重试模型。并发默认3、待处理容量30；已有用户任务未完成时不能创建第二个。

预留额度与任务token落盘、成功结算与结果保存分别使用事务；失败结算幂等。SQLite和MariaDB迁移32增加配置、额度和任务表。部署前按统一发布脚本备份，迁移不覆盖旧用户内容。

## 来源与限制

Anatomy：https://github.com/wheresryan22/anatomy ，固定提交bc943e40c59998be5da61f9d39c6a983b1116099；public/vendor/anatomy保留MIT许可证及上游信息。只采用审阅过的几何核心；上游截图、审计或任意脚本不作为在线执行接口。

最多80零件、12步骤、6滑块、10变量，场景文本48000字符；表达式白名单、深度和范围限制，校验初始、步骤、边界及组合状态。模型文本不作为SVG/HTML或JS执行，属性文本由绘图库转义。没有声称完整采用上游的物理碰撞与光线审计，也没有保证任意主题都能成功生成。


## 2026-10-19 可见性与演示修复

绘制先处理底座与上层部件的支撑关系，避免按中心深度排序时把主体盖住。播放在相邻步骤参数间连续变化，暂停后继续当前动作；步骤可直接定位。取景包含中间状态，出现未采样极值时只扩展范围，避免主体跑出画布。支持动态减少运动偏好。

部件增加 sphere（椭球）与 profile（有厚度的平滑竖直轮廓）；profile 只能提交3至64个[-0.5,0.5]二维数字点，禁止任意SVG/代码。palette可选slate、blue、coral、teal、amber、violet；scale为0.1至3的有限数字或受控AST，表达收缩/膨胀。旧场景默认scale=1并保持兼容。轮廓依然是简化教学图形，不是写实器官、人物模型或完整自由建模。

焦点部件增加名称引线；绘制失败显示所在步骤和重置/修改操作。模型finish_reason=length直接按输出截断失败并退款，不再将空内容或不完整内容作为普通语法错误再修正。非截断的无效场景仍最多修正一次。缩小生成要求以减少无效复杂度，所有真实模型生成仍受上游可用性和输出质量限制。
