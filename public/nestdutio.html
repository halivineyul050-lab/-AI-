发布准备（请按实际完成情况勾选）
  1. 下载完整工程，解压后在微信开发者工具选择“导入项目”，填入自己的 AppID。
  2. 在开发者工具编译，修复控制台问题，再用“预览”生成真实二维码并在手机验证。
  3. 也可按 ZIP 中 README 使用本地 CLI 脚本；电脑需安装微信开发者工具并开启服务端口。网页不能调用你的本地工具。
  4. 手机验证完成后，在开发者工具上传，进入微信公众平台填写资料、提交审核。审核通过后由你确认发布。
本地命令示例
在已解压的工程目录打开终端，将 CLI 路径替换为微信开发者工具的实际路径。先在工具中登录并开启服务端口；二维码文件必须尚不存在。
node nestdutio-wechat-devtools.mjs doctor --cli "微信开发者工具CLI路径"
node nestdutio-wechat-devtools.mjs preview --cli "微信开发者工具CLI路径" --project "." --qr-output "./preview-qr.png"
二维码由你的微信开发者工具真实生成。本地需要 Node.js；上传命令及完整排错见工程 README。
